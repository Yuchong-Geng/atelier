# Benchmark Digest

## Status

Scored on 2026-05-12.

## Research Question

Does research-agent improve early research orientation compared with a freeform model response?

## Claim Under Test

Research-agent should improve correctness and recoverability in early research workflows by forcing the model to separate sourced facts, assumptions, evaluation criteria, failure modes, and bounded next actions.

## Result Summary

Research-agent scored higher on two of three tasks and tied on the third.

| Task | Baseline | Research-Agent | Difference |
| --- | ---: | ---: | ---: |
| NeuroGolf orientation | 10 | 14 | +4 |
| AI4Research claim extraction | 12 | 16 | +4 |
| Correctness eval design | 16 | 16 | 0 |
| Mean | 12.67 | 15.33 | +2.67 |

No severe correctness errors were observed in either condition.

The main gain was not factuality on easy prompts. The baseline was already capable when the task directly asked for a detailed eval design. The gain appeared when the prompt was vague or when the model needed to avoid overclaiming from partial evidence.

## Qualitative Read

Task A showed the clearest orientation benefit. The baseline identified a plausible NeuroGolf direction and useful first steps, but it did not explicitly mark the official Kaggle rules as unavailable from the packet. The research-agent output separated source facts, assumptions, risks, and bounded next moves.

Task B showed the strongest claim-discipline benefit. The baseline was careful, but the research-agent output cleanly separated supported, weak, and unsupported paper claims. It also named the exact missing evidence needed before making stronger correctness claims.

Task C showed that a strong baseline can match the protocol when the prompt already demands a precise eval. Both outputs proposed small no-GPU correctness audits with answer keys, scoring, failure criteria, and paper-facing interpretation. The research-agent version was more tailored to this project, but the rubric did not reward that beyond a tie.

## Paper-Facing Interpretation

The paper should not claim that research-agent improves final research outcomes.

The defensible claim is narrower:

> In a three-task pilot on early research orientation, claim extraction, and correctness-evaluation design, the research-agent protocol improved manual rubric scores over freeform prompting on vague or claim-sensitive tasks while tying a strong freeform baseline on an explicit evaluation-design task.

This result supports a workshop-paper argument about correctness-oriented workflow structure:

- source facts and assumptions are made explicit
- constraints are less likely to be dropped
- claims are separated by support level
- failure modes and falsification criteria are surfaced earlier
- outputs are easier for a later agent or researcher to resume

The result should be framed as a pilot and a demonstration, not as statistically powered evidence.

## Severe Error Log

No severe errors were recorded.

The main baseline errors were weaker source uncertainty and weaker recoverability, not hallucinated source facts.

## Limitations

The sample size is three tasks and six outputs.

The outputs were generated by same-family agents in one environment, so the benchmark does not establish cross-model generality.

The scorer was not blind to condition labels.

The NeuroGolf source context relied on an accessible third-party summary because the official Kaggle page did not expose crawlable text in this session.

The benchmark measures orientation quality, claim discipline, and eval design. It does not measure final competition performance, real scientific discovery, or long-horizon productivity.

The research-agent condition is longer on two tasks, so future scoring should include an overhead or concision-adjusted measure.

## Next Evaluation Step

For the workshop paper, the next step should be one of two small replications.

1. Run a blinded scoring pass by masking file names and condition labels.
2. Add one real artifact-checking task with an answer key, such as checking a small derivation, config-to-claim mismatch, or paper table claim.

The first option is faster and strengthens the current result. The second option better addresses correctness beyond orientation.
