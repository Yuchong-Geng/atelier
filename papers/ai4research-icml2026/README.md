# AI4Research ICML 2026 Workshop Paper

This folder contains the accepted ICML 2026 Workshop AI4Research paper source for Atelier.

Paper: <https://openreview.net/forum?id=9h3ZudPP3G>

Project page: <https://yuchong-geng.github.io/project-page/atelier.html>

Code: <https://github.com/Yuchong-Geng/atelier>

Workshop: <https://ai4research-icml-workshop.github.io/>

The source template was copied into this folder so paper changes can be tracked with the Atelier implementation and evaluation artifacts.

Build from this folder with:

```sh
latexmk -pdf main.tex
```
